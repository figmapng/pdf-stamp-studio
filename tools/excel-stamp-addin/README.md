# PDF Stamp Studio — Надстройка Excel и программа настройки для Windows

Инструмент позволяет **в 1 клик экспортировать готовый протокол Excel в единый PDF с автоматически проставленными подписями и печатью**.

---

## 🌟 Как работает система?

1. **Администратор / Настройка (только 1 раз):**
   - Запускает `Setup.bat` (или скомпилированный `PdfStampSetup.exe`).
   - Открывается графическое окно настройки.
   - Проверяет параметры подписывающих лиц (ФИО, должность, файл подписи PNG) и печати организации (ТОО «Ecology Expert»).
   - Нажимает кнопку **«🚀 Сохранить и установить в Excel»**.
   - Закрывает окно.

2. **Обычный сотрудник (ежедневная работа):**
   - Программу настройки открывать не нужно.
   - Открывает любой свой стандартный протокол `.xlsx` в Excel.
   - Нажимает кнопку **«Создать PDF с подписями»** в верхней панели Excel (или нажимает горячие клавиши **`Ctrl + Shift + P`**).
   - Excel автоматически находит строки подписей, проставляет подписи и печать, экспортирует все листы в один единый PDF и сразу открывает его на экране.
   - Исходная таблица Excel остается абсолютно чистой.

## 📁 Структура файлов

- **`PdfStampConfigurator.py`** — Графическая программа настройки для Windows.
- **`PdfStampConfigurator.ps1`** — Автономный скрипт графического интерфейса PowerShell (работает без установки Python).
- **`install.ps1`** — Скрипт автоматической компиляции и интеграции надстройки в системную папку `XLSTART` программы Excel.
- **`Setup.bat`** — Запуск программы настройки в 1 клик.
- **`vba/PdfStampModule.bas`** — Исходный VBA-модуль надстройки для Excel.

---

## 🔒 Безопасность и хранение файлов

Все данные сотрудников и печати сохраняются в защищенную системную папку пользователя:
`%APPDATA%\PdfStampStudio\` (`C:\Users\<Имя_Пользователя>\AppData\Roaming\PdfStampStudio\`)
- `signatures/` — Файлы подписей в формате PNG
- `stamps/` — Файл печати в формате PNG
- `config.ini` — Файл настроек
