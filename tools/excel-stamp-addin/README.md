# PDF Stamp Studio — Excel Add-in & Windows Баптаушысы

Бұл құрал қарапайым жұмысшыларға **кез келген дайын Excel хаттамасын 1 кликпен қолы мен мөрі қойылған PDF-ке айналдыруға** мүмкіндік береді.

---

## 🌟 Жүйе қалай жұмыс істейді?

1. **Әкімші / Баптаушы (1 рет қана):**
   - `Setup.bat` файлын ашады (графикалық терезе ашылады).
   - Қол қоюшыларды (Аты-жөні, қызметі, PNG қолтаңба суреті) және мекеме мөрін (PNG) таңдайды.
   - **«🚀 Баптауларды сақтау және Excel-ге орнату»** батырмасын 1 рет басады.
   - Бағдарламаны жауып тастайды.

2. **Қарапайым жұмысшы (Күнделікті жұмыс):**
   - Баптау бағдарламасын ашпайды да, көрмейді де.
   - Өзінің кез келген әдеттегі `.xlsx` хаттамасын Excel-де ашады.
   - Excel-дің жоғарғы мәзіріндегі **«PDF жасау және қол қою»** батырмасын (немесе **`Ctrl + Shift + P`**) басады.
   - Excel кестеден аты-жөндерді өзі танып, қол мен мөрді қойып, барлық листтерді 1 тұтас PDF қылып сақтайды және экранға ашып береді.
   - Excel кестесі таза күйінде қалады.

---

## 📁 Файлдар құрылымы

- **`PdfStampConfigurator.py`** — Windows графикалық баптау бағдарламасы.
- **`install.ps1`** — Excel-дің ішкі `XLSTART` жүйелік папкасына автоматты түрде надстройка орнататын PowerShell скрипті.
- **`Setup.bat`** — 1 кликпен баптаушыны іске қосатын Windows файлы.
- **`vba/PdfStampModule.bas`** — Excel ішінде жұмыс істейтін жеңіл әрі сенімді қозғалтқыш (Add-in кодын сақтайды).

---

## 🔒 Қауіпсіздік және Сақталу орны

Барлық қол қоюшылар мен мөр деректері жұмысшының көзіне көрінбейтін, кездейсоқ өшірілмейтін қорғалған жүйелік папкаға сақталады:
`%APPDATA%\PdfStampStudio\` (`C:\Users\<Атыңыз>\AppData\Roaming\PdfStampStudio\`)
- `signatures/` — Қолтаңба суреттері
- `stamps/` — Мөр суреттері
- `config.ini` — Барлық параметрлер
