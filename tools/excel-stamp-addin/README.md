# PDF Stamp Studio — кнопка в Excel

Подписи и печать ставятся **прямо из Excel**: не нужно сохранять файл и переносить его в программу.

## Как работает

1. **Настройка (в программе PDF Stamp Studio, вкладка «Подпись и печать»)**: добавить подписантов (имя, должность, PNG подписи) и печати. Фон у фото подписи и печати вырезается автоматически (без интернета). Программа сама записывает всё в `%APPDATA%\PdfStampStudio\` (`config.ini` + `assets\*.png`).
2. **Работа в Excel** (вкладка «Главная» → группа «Подписи и печать»):
   - **1. Показать подписи** — находит подписантов в файле и кладёт их подпись и печать на лист обычными картинками. Неточное положение исправляется перетаскиванием мышью.
   - **2. Сохранить PDF** — все видимые листы в том же порядке сохраняются в один PDF рядом с Excel-файлом. Картинки после этого убираются, сам Excel-файл не меняется.
   - **Убрать** — убрать картинки без сохранения. **Настройки** — открыть программу.
   - Горячая клавиша `Ctrl+Shift+P`: первое нажатие показывает подписи, второе сохраняет PDF.

## Файлы

- `vba/PdfStampModule.bas` — движок (поиск имён в ячейках, расстановка, экспорт PDF).
- `customUI14.xml` — кнопки на ленте.
- `install.ps1` — собирает `PdfStampStudio.xlam` и ставит в `XLSTART` (поддерживает Excel 2010–365). Кириллица в VBA кодируется как `\uXXXX`, поэтому работает при любой кодовой странице Windows.
- `Установить_в_Excel.bat`, `Удалить_из_Excel.bat` — запуск `install.ps1`.

## Как подписант ищется в файле

По всем видимым листам ищется ячейка, где встречается ФИО (или любой из вариантов написания, или уникальная фамилия). Приоритет у ячеек со строкой `______` для подписи; положение вычисляется по центру этой линии. Если ничего не найдено, программа об этом сообщит, и подпись можно поставить вручную.


## Совместимость и особенности

| Что | Как учтено |
|---|---|
| Excel 2007 … Microsoft 365, 32 и 64 бит | В VBA нет `Declare` и внешних ссылок; лента для Excel 2010+ (`customUI14`) и для 2007 (`customUI`) |
| Любой язык Windows / имя пользователя на кириллице или казахском | Кириллица в VBA хранится как `\uXXXX`; конфиг читается как UTF-16; пути берутся через Unicode-функции |
| WPS Office на том же ПК | Установщик проверяет, что запущен именно Microsoft Excel (имя и версия), WPS игнорируется |
| Excel уже открыт | Сборка идёт во временную папку; старая надстройка закрывается в открытом Excel; новая подключается без перезапуска |
| «Доверять доступ к объектной модели VBA» выключен | Включается только на время установки и возвращается обратно; при запрете администратором показывается инструкция |
| Корпоративные запреты на `Scripting.Dictionary` / WScript / ADODB | Не используются или есть запасной вариант |
| Огромные листы | Лист читается блоками, а не одним массивом |
| Файл открыт в Acrobat, папка только для чтения, OneDrive/SharePoint, длинный путь | PDF сохраняется в запасное место (с отметкой времени, «Документы», «Рабочий стол») |
| Защищённый лист / режим защищённого просмотра | Понятное сообщение; пустой пароль снимается автоматически |
| Крупные фото подписи (4000 px+) | Уменьшаются до 1400 px перед отправкой в Excel |

Не поддерживается: Excel для Mac, Excel Online, Excel 2003 и старше, Excel Starter. Программа PDF Stamp Studio рассчитана на Windows 10/11.
Журнал установки: `%APPDATA%\PdfStampStudio\install.log`.
