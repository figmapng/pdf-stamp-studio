PDF STAMP STUDIO — ИНСТРУКЦИЯ ПО УСТАНОВКЕ В MICROSOFT EXCEL
ТОО «Ecology Expert» — Автоматическая расстановка подписей и печати
=========================================================================

Поддерживаются ВСЕ версии Microsoft Excel:
Excel 2010, Excel 2013, Excel 2016, Excel 2019, Excel 2021, Office 365.

КАК УСТАНОВИТЬ КНОПКУ В EXCEL ЗА 1 КЛИК:
----------------------------------------
1. Закройте Microsoft Excel, если он сейчас открыт.
2. Дважды щелкните по файлу «Установить_в_Excel.bat».
3. Дождитесь надписи: «[УСПЕХ] Надстройка успешно установлена!».
4. Откройте любой файл Excel (протокол испытаний) — на вкладке «Главная» 
   в правой части панели появится большая кнопка:
   «Создать PDF с подписями» (или нажмите клавиши Ctrl + Shift + P).

КАК РАБОТАЕТ КНОПКА:
---------------------
1. Вы нажимаете «Создать PDF с подписями» (или Ctrl+Shift+P).
2. Программа автоматически находит в протоколе:
   - Инженер-химик Затыбек А. А. -> вставляет подпись точно на линию
   - Заведующий лабораторией Сатыбалдина З. С. -> вставляет подпись точно на линию
   - Сатыбалдина З. С. -> ставит официальную круглую печать ТОО «Ecology Expert»
3. Все листы протокола объединяются и сохраняются в один чистый PDF файл 
   с окончанием «_утвержденный.pdf» в той же папке, где лежит файл Excel.
4. Готовый PDF сразу автоматически открывается для проверки!

КАК УДАЛИТЬ КНОПКУ ИЗ EXCEL:
----------------------------
Если понадобится удалить кнопку, просто запустите файл «Удалить_из_Excel.bat».
