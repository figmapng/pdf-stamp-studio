PDF STAMP STUDIO — ИНСТРУКЦИЯ ПО УСТАНОВКЕ В MICROSOFT EXCEL
ТОО «Ecology Expert» — Автоматическая расстановка подписей и печати
=========================================================================

Поддерживаются ВСЕ версии Microsoft Excel:
Excel 2010, Excel 2013, Excel 2016, Excel 2019, Excel 2021, Office 365.

СПОСОБ 1: БЫСТРАЯ УСТАНОВКА ЗА 1 КЛИК
-------------------------------------
1. Закройте Microsoft Excel, если он сейчас открыт.
2. Дважды щелкните по файлу «Установить_в_Excel.bat».
3. Дождитесь зеленой надписи: «[УСПЕХ] Надстройка успешно установлена!».
4. Откройте любой файл Excel (протокол) — на вкладке «Главная» 
   в правой части панели появится большая кнопка:
   «Создать PDF с подписями» (или нажмите клавиши Ctrl + Shift + P).

СПОСОБ 2: ИЗМЕНЕНИЕ НАСТРОЕК (КООРДИНАТЫ, ФАЙЛЫ, РАЗМЕРЫ)
---------------------------------------------------------
Если вы хотите изменить смещение подписей, заменить файлы картинок 
или отредактировать ключевые слова:
1. Запустите файл «Настройка_и_Установка_в_Excel.bat».
2. Откроется удобное окно настройки, где можно настроить:
   - 1-й подписывающий: Инженер-химик Затыбек А. А.
   - 2-й подписывающий: Заведующий лабораторией Сатыбалдина З. С.
   - Мекеме мөрі: Печать ТОО «Ecology Expert»
3. Нажмите кнопку «⚡ Сохранить и установить в Excel».

КАК УДАЛИТЬ КНОПКУ ИЗ EXCEL:
----------------------------
Если понадобится удалить кнопку из программы Excel, 
просто запустите файл «Удалить_из_Excel.bat».
